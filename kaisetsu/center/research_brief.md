## 入力
- 問題: /Users/komorily55/jotf/06_sushi/chorishi/kaisetsu/center/questions.json （公益社団法人 調理技術技能センターの令和5〜7年度 本試験。id は "CR5-1" の形。answer が公式の正解番号。invalidated=true は「不適切問題で全員正解」）
- 書き方の手本（静岡の過去問の解説。形と口調をまねる）: /Users/komorily55/jotf/06_sushi/chorishi/kaisetsu/data/part_01.json と part_05.json

## やること
担当の問題すべてについて、各選択肢が正しいか誤りかを、**調べて確かめてから**解説を書く。
- WebSearch / WebFetch で根拠を確認する。優先する情報源：厚生労働省・消費者庁・文部科学省・農林水産省・e-Gov法令検索・食品安全委員会・日本食品標準成分表・日本人の食事摂取基準など公的な資料。市販テキストの一般的な記述で足りる調理理論などは、無理に検索しなくてよいが、数字・法律・制度・統計は必ず確かめる。
- 公式の正解（answer）と、あなたの判断が食い違ったら、そのまま正直に flag に書く（公式の正解は変えない）。
- 試験後に制度・統計・基準が変わったもの（例：健康日本21 第二次→第三次、日本人の食事摂取基準 2020→2025年版、アレルギー表示の特定原材料の追加、規格基準の所管が厚労省→消費者庁 など）は update に「今はどうなっているか」と「正解は変わるか」を書く。今日は 2026年10月18日。
- 静岡県の試験とも共通する重要論点なら points にそう分かる書き方をしてよい（必須ではない）。

## 出力
担当ファイル（下記）に JSON 配列で書く。問題の順番どおり。各要素：
```
{
  "id": "CR5-1",
  "tag": "短いテーマ名（例：保健所）",
  "choices": [ {"verdict": "正しい" または "誤り", "note": "解説文"}, ...4つ ],
  "points": ["覚えるポイント", ...2〜3個],   // ほぼ全問につける
  "update": null または "最新の制度の補足",
  "invalidNote": null または "不適切問題だった理由の推測（invalidated=true の問題だけ）",
  "flag": null または "公式正解への疑問など（内部用）",
  "textIssue": null または "問題文の抽出ミスらしき点（内部用）"
}
```
- verdict は「その選択肢の記述が正しいか」。正解かどうかではない（「誤っているものを選べ」の問題では、正解の選択肢の verdict は「誤り」になる）。正解の印は表示側で付けるので、note に「これが正答です」と書いてよい。
- 組合せ・空欄補充の問題は、その組合せが正しいかで verdict を付け、note で各語句を説明する。
- note は1〜3文。平易な日本語。大事な語句だけ `<strong>…</strong>` で囲む。**タグは <strong> 以外使わない**。Markdownも使わない。
- 選択肢は必ず4つ。
- 書き終えたら `python3 -c "import json;d=json.load(open('<担当ファイル>'));print(len(d))"` で JSON として読めるか、件数が合っているか確認する。

## 最後に返すこと（短く）
件数、flag を付けた問題とその理由、update を付けた問題の一覧、問題文の抽出ミスに気づいたもの。
